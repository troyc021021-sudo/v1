# 目标用户画像

> 状态：v0.2。阶段 3 用真实账号数据校验后修订。
>
> ⚠️ v0.2 修正：品类是「可爱高级性感内衣」而非 cosplay 内衣，
> 因此 B 类的定义从「weeb / cosplayer」收窄为「被东亚少女美学吸引的女性」——
> cosplayer 是其中一部分，不是全部。

## 优先级排序

**A 类（主攻）> B 类（主攻）> C 类（机会）**
A 和 B 加起来应占首年营收 80%。

---

## A. 日韩本土「量産型 / girly」女生

| 维度 | 描述 |
|---|---|
| 年龄 | 20–28 |
| 地域 | 东京、大阪、首尔、釜山 |
| 自我认同 | 量産型 / 地雷系 / 白ホワイト系 / 韩系"清纯欲" |
| 消费动机 | **自我取悦、拍照、收藏**。买内衣不是为了给谁看，是"今天想当这个角色" |
| 信息渠道 | Instagram（主）、X/Twitter、TikTok、LINE、Naver Blog（韩） |
| 关键词 | `#ランジェリー` `#量産型` `#地雷系` `#ロリータ` `#下着コーデ` `#란제리` `#여성속옷` |
| 价格接受度 | 日本对 ¥10,000–18,000（约 $70–125）一套的设计师内衣接受度高；韩国略低 |
| **决策关键点** | **尺码精确度**。日韩用户极度看重尺寸表、材质成分、着用感描述。尺码不清 = 不下单 |
| **雷点** | 男凝式文案、"性感取悦他"的叙事、粗糙的英文机翻 |

**给我们的启示**：日语/韩语必须是人工文案而非机翻；尺寸表必须本地化（日式罩杯体系 ≠ 欧美）。

## B. 欧美「Asian aesthetic / J-fashion」女性

| 维度 | 描述 |
|---|---|
| 年龄 | 20–30 |
| 地域 | 美国（加州/纽约/德州）、英国、德国、法国、澳洲 |
| 自我认同 | 被东亚少女美学吸引的女性：coquette / soft girl / lolita / J-fashion / alt-girl（cosplayer 是子集，非全部） |
| 消费动机 | **角色代入 + 社群身份**。她们买的是"我属于这个圈子"的凭证 |
| 信息渠道 | Instagram、TikTok、Pinterest、Reddit（r/lolita, r/JFashion, r/femalefashionadvice）、Discord |
| 关键词 | `#coquette` `#softgirlaesthetic` `#jfashion` `#lolitafashion` `#lingerieaddict` `#kawaiifashion` |
| 价格接受度 | **最高**。习惯为 J-fashion 单品付 $100–300（Lolita 圈一条裙子 $200+ 是常态） |
| **决策关键点** | **尺码包容性**。欧美体型跨度大，只做亚洲码 = 大量差评。需要到 XL/2XL |
| **雷点** | 尺码不全、发货 30 天、"looks nothing like the photo" |

**给我们的启示**：这是**客单价最高、最愿意为叙事付费**的一群人，也是 $109 定价最有支撑的市场。
但对尺码和物流时效的要求最狠——这两点做不好，前面所有品牌工作归零。

## C. 高端内衣审美者（机会层，不主攻）

| 维度 | 描述 |
|---|---|
| 年龄 | 25–35 |
| 已在买 | Fleur du Mal、Agent Provocateur、Lounge、Savage X |
| 被什么吸引 | "东方叙事"的新鲜感、独立设计师感、包装体验 |
| 渠道 | Instagram、Pinterest |
| 风险 | 她们的材质和工艺标准高于我们 ¥100 货值能提供的水平 |

**策略**：不主动投放这层，用**视觉溢出**被动获取（她们会被好看的 IG 内容吸引过来）。
等供应链能力升级后再正面进攻。

## 反向画像：我们不服务谁

- 找便宜 cosplay 的学生（预算 $20–30）
- 男性买家为伴侣选购（这是另一套完全不同的文案和渠道，会污染品牌调性）
- 成人用品/情趣用品消费者（品类邻近但心智完全不同，混在一起会拖垮溢价）

> ⚠️ 最后一条尤其重要：**把自己放在"服饰/J-fashion"心智里，而不是"成人用品"心智里**，
> 这一个选择同时决定了定价上限、广告能否投放、支付通道能否开通、KOL 愿不愿意合作。
