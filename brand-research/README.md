## 已确认的关键决策

1. **不用真人模特**，采用「插画主导（AI）+ 产品实拍为真」三层影像分工 → `00-brief/01-positioning.md` §4
2. **建站用 Shopify**，不自建后端
3. **定价 $89–129，锚定 $109**；$40–50 零售在付费投放下必亏 → `07-pricing/`
4. **心智归属「服饰 / J-fashion」，不归「成人用品」** → `00-brief/02-personas.md`

## 素材版权原则

本仓库**不批量存放他人版权图片**。视觉参考以「链接 + 结构化分析」形式记录在 `03-moodboard/`，
需要图形化参考板时使用私密 Pinterest board（链接清单由 `03-moodboard/` 提供）。
