## 已确认的关键决策

1. **不用真人模特**，采用「插画主导（AI）+ 产品实拍为真」三层影像分工 → `00-brief/01-positioning.md` §4
2. **建站用 Shopify**，不自建后端
3. **品类 = 可爱 · 高级 · 性感内衣**，女仆只是一个系列，**不是 cosplay 品牌** → `00-brief/01-positioning.md` §1
4. **定价 ¥15,800（约 $105）一步到位，货值同步从 ¥55 升到 ¥90**（毛利 49.1%）。
   上限由日本免税线锁死（零售 ≤ ¥16,667），下限由 RAVIJOUR / SALON by PEACH JOHN 的价格带决定 → `01-competitors/00-landscape-map.md` §4
5. **首发日本**，新马同期，韩国第 2-3 季，东南亚其余推迟到第 2 年走 Shopee/TikTok Shop 副线 → `00-brief/03-market-priority.md`
6. **心智归属「服饰 / J-fashion」，不归「成人用品」** → `00-brief/02-personas.md`
