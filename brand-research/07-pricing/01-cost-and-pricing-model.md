# 成本结构与定价模型

> 汇率假设 1 USD = 7.10 RMB。所有金额为**单件（一整套）**口径。
> 模型脚本见 `07-pricing/pricing_model.py`，改参数可重算。

## 1. 成本项拆解

| 成本项 | 说明 | 基准值 |
|---|---|---|
| COGS 货值 | 工厂出厂价 ¥100 | **$14.08** |
| 品牌包装 | 外盒 + 缎带 + 防尘袋 + 角色卡 + 感谢卡 + 贴纸 | $2.5 / $5 / $9（三档） |
| 国际运费 | 300–400g，中国直发专线（4PX / YunExpress / 燕文） | $5–9（美线）；日韩线更便宜 $3–5 |
| **CAC 获客成本** | **最大变量，见 §3** | $10–60 |
| 支付手续费 | Shopify Payments / Stripe，2.9% + $0.30 | 按零售价算 |
| 退换损耗 | 内衣类可设 final sale，退货率压到 4–8% | 按 6% 计 |
| 固定分摊 | Shopify $39/mo + App + 域名 + 摄影，按月 100 单摊 | ~$1.5 |

## 2. 零售价敏感性（其他参数固定：包装 $5、运费 $7、CAC $25）

| 零售价 | 总成本 | 毛利 | 毛利率 | 判定 |
|---|---|---|---|---|
| $49 | $55.41 | **−$6.41** | −13.1% | ❌ **亏损** |
| $69 | $56.02 | $12.98 | 18.8% | ⚠️ 活不下去（毛利率 <30% 无法再投放） |
| $89 | $56.64 | $32.36 | 36.4% | ⚠️ 勉强，容错率低 |
| **$109** | $57.25 | **$51.75** | **47.5%** | ✅ **健康线** |
| $129 | $57.87 | $71.13 | 55.1% | ✅ 舒适 |
| $149 | $58.48 | $90.52 | 60.8% | ✅ 需要品牌力支撑 |

> **关键结论：$40–50 的零售价在付费投放模式下必亏。**
> 原因不是货值贵（货值只占 13%），而是 **CAC + 国际运费 ≈ $32**，这是跨境 DTC 的硬地板。
> 只有在"零付费投放 + 纯自然流量"下 $49 才勉强能活（见路线 A），但那意味着增长完全不可控。

## 3. CAC 敏感性（零售价固定 $109）

| CAC | 毛利率 |
|---|---|
| $10（KOC / 自然流量为主） | 61.2% |
| $20 | 52.1% |
| $30 | 42.9% |
| $45 | 29.1% |
| $60（冷启动期 Meta 实际常见值） | 15.4% |

> **CAC 比定价更致命。** 冷启动期 Meta/TikTok 在情趣内衣品类的 CAC 常见在 $35–60，
> 而且这个品类广告账户还容易被封。所以**内容/KOC 驱动是必选项，不是可选项**——
> 它不只是省钱，它是这个生意能不能成立的前提。

## 4. 三条路线对比

| | A. 中端走量 | **B. 中高端（推荐）** | C. 高端限量 |
|---|---|---|---|
| 零售价 | $49 | **$109** | $149 |
| 货值 | ¥100 | ¥100 | ¥130（升级面料/工艺） |
| 包装 | $2.5 简装 | **$5 品牌盒 + 角色卡** | $9 礼盒 + 编号 + 画集卡 |
| 运费 | $5 平邮 | **$7 专线可追踪** | $9 专线 + 保价 |
| CAC | $12（几乎不能投放） | **$25** | $30 |
| 毛利 | $11.36 | **$51.75** | $74.85 |
| 毛利率 | 23.2% | **47.5%** | 50.2% |
| 风险 | 和 Amazon/速卖通同行正面价格战，供应链同质，无护城河 | 需要建立品牌叙事 | 需要先有品牌资产才卖得动 |

### 推荐：从 B 起步，用 C 做形象款

- **主力价格带 $89–129**，核心 SKU 锚定 **$109**
- 同时上 1 款 **$149–189 限量款**（编号 + 特殊包装）——它的作用不是走量，是**把 $109 衬托成"理性选择"**（价格锚定）
- **不要**做 $49 档。要做入门款就做**配件**（$29 的袜子/choker/发饰），用来提客单和凑免邮门槛

## 5. 客单价（AOV）提升杠杆

单件 $109 的 CAC 承受力有限。真正让模型跑通的是 **AOV 拉到 $140–160**：

| 杠杆 | 做法 | 预期提升 |
|---|---|---|
| 免邮门槛 | "满 $129 免国际运费" | +15–25% AOV |
| 配件搭售 | 同系列过膝袜 $29 / choker $19 / 发饰 $15 | +$20–40 |
| 套装折扣 | 买两套 −15% | 转化率 +，AOV + |
| 角色卡收集 | 每套附不同角色卡，集齐有隐藏款 | 复购驱动 |

## 6. 待你确认/补充的真实数据

这个模型现在跑在**假设值**上。把下面几个数字告诉我，我立刻重算成精确版：

1. **出厂价** ¥100 是含税含运到你仓库吗？还是裸价？
2. **重量** 一整套（含包装）大概多少克？决定运费档位。
3. **首发市场** 先打美国、日本还是韩国？三地运费和 CAC 差很多（日韩运费更低但客单价接受度也不同）。
4. **备货能力** 首批能压多少货值？决定能不能上"限量编号"玩法。
5. **是否已有 Shopify Payments 可用**？情趣内衣类目部分支付通道会拒（见 `06-site-blueprint`）。
